# 🏡 VivaHome Inmobiliaria

> Plataforma web inmobiliaria moderna, elegante y de alto rendimiento para el mercado de bienes raíces en Perú (Lima Top, balnearios y proyectos residenciales).

---

## ✨ Características Principales

- **Identidad Visual Premium**: Paleta Esmeralda Residencial, tipografía *Plus Jakarta Sans*, modo oscuro sofisticado y efectos glassmorphic.
- **Catálogo de Propiedades**: Fichas completas con galería, especificaciones (m², habitaciones, baños), precios duales (USD / PEN), mapa de ubicación interactivo y contacto directo por WhatsApp.
- **Servicios Inmobiliarios**: Detalle paso a paso de servicios (Compraventa, Asesoría Legal Sunarp, Tasaciones, Inversión).
- **Equipo de Brokers**: Perfiles profesionales detallados con habilidades, trayectoria e información de contacto directo.
- **Blog Inmobiliario**: Artículos informativos con tiempo de lectura, autor y estructuración editorial optimizada.
- **Formulario de Contacto & FAQ**: Preguntas frecuentes notariales/legales con acordeón animado y formulario de consulta interactivo.
- **Experiencia de Usuario Fluida**: Animaciones con `framer-motion`, diseño 100% responsivo y soporte para anclas de navegación.

---

## 🛠️ Stack Tecnológico

- **Core**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Estilos**: Tailwind CSS v4
- **Enrutamiento**: React Router v7
- **Animaciones**: Framer Motion
- **Iconografía**: Lucide React

---

## 🚀 Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Kactis-Labs/Vivahome.git
   cd Vivahome
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
